# YANSHUN PORTFOLIO

A static personal portfolio website for exhibition planning, product marketing design and brand visual guideline work.

## Preview

Open `index.html` directly in a browser, or run a local static server:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

- `index.html` - page structure
- `styles.css` - visual system and responsive layout
- `app.js` - work data, filters and project detail modal
- `assets/images` - selected image assets copied from the workspace
- `assets/video` - selected video asset
